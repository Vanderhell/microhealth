# Contributing

In scope: bug fixes, docs, tests, new well-known metric IDs.
Out of scope: hard dependencies on other libraries, dynamic allocation.

1. Open issue. 2. Fork, branch, test. 3. PR.
By contributing, you agree to the MIT License.

Before opening issues or PRs, read:

- `README.md`
- `docs/API_REFERENCE.md`
- `docs/COOKBOOK.md`
- `docs/FAQ.md`
- `SUPPORT.md`

For vulnerabilities, use `SECURITY.md` instead of a public issue.
